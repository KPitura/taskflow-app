# TaskFlow - Aplikacja do zarządzania zadaniami

Prosta aplikacja webowa typu To-Do stworzona w ramach laboratorium z wykorzystaniem GitHub, GitHub Projects oraz przepływu pracy opartego na gałęziach i Pull Requestach.

## Technologie
- **Back-End:** Node.js, Express, system plików JSON jako warstwa persystencji danych
- **Front-End:** HTML5, CSS3, Vanilla JavaScript (Fetch API)
- **Narzędzia:** Git, GitHub, GitHub Issues, GitHub Projects

## Uruchomienie projektu
1. Sklonuj repozytorium:
   `git clone https://github.com/KPitura/taskflow-app.git`
2. Zainstaluj zależności:
   `npm install`
3. Uruchom serwer:
   `node server.js`
4. Otwórz przeglądarkę i przejdź pod adres: `http://localhost:3000`
